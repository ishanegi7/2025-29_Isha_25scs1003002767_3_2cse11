## 📌 Project Overview

**EduAccess** is an open-access web application built in alignment with **UN Sustainable Development Goal 4 (SDG 4: Quality Education)**. The platform aims to bridge the digital learning divide by providing free, structured, and easily accessible educational resources, course notes, and learning materials to self-learners and students without paywalls or subscription barriers.

---

## 🎯 Key Objectives

- **Democratize Education:** Deliver free learning content to students regardless of their socioeconomic background.
- **Centralized Learning:** Gather structured study materials for core subjects like Web Development, Python, and Data Structures in one place.
- **Interactive Experience:** Allow students to request new course materials and submit feedback through a dynamic user interface.
- **Responsive Architecture:** Ensure seamless accessibility across desktop, tablet, and mobile devices.

---

## ✨ Features

- 📱 **Mobile-First Responsive Layout:** Built using modern CSS Grid and Flexbox to adapt automatically to any screen size.
- 🧭 **Intuitive Navigation:** Smooth navigation bar with quick anchor links across all page sections.
- 📚 **Subject Resource Library:** Card-based UI showcasing different course modules and structured study guides.
- 📝 **Resource Request Form:** Interactive frontend form with JavaScript validation for dynamic resource requests.
- ⚡ **Lightweight & Fast:** Pure HTML/CSS/JS stack with zero heavy external dependencies for fast page loads in low-bandwidth areas.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5 (Semantic Tags), CSS3 (Flexbox, CSS Grid, Media Queries), JavaScript (ES6+, DOM Manipulation)
- **Version Control:** Git & GitHub
- **Deployment Platform:** GitHub Pages
- **Development Environment:** Visual Studio Code (Live Server extension)
